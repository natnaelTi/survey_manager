# Survey Manager

A powerful Frappe application for creating, managing, and analyzing surveys.

## Features

- Create and manage custom surveys  
- Multiple question types support  
- Survey response tracking  
- Analytics and reporting  
- Export survey data  
- Role-based access control  

## Installation

Install the Survey Manager app in your Frappe instance:

```bash
bench get-app survey_manager https://github.com/your-repo/survey_manager
bench --site your-site.local install-app survey_manager
```

## Configuration

After installation, the Survey Manager will be available in your Frappe desk.

- Set up user permissions through **Role Permission Manager**  
- Configure survey settings through **Survey Manager Settings**  

## Usage

### Creating a Survey

1. Navigate to **Survey Manager > New Survey**  
2. Add survey details and questions  
3. Configure visibility and access settings  
4. Save and publish  

### Managing Responses

- View responses in real-time  
- Export response data  
- Generate analytics reports
